## Standards

**P2 — Permissions теряет null внутри объекта прав.**
`model/permission.go:67–71`: декодирование в map[string]PermissionScope успешно
принимает JSON null, превращая его в пустую строку; fallback в Raw не срабатывает.
Обоими codecs `{"future":{"view":null}}` после чтения/записи превращается в
`{"future":{"view":""}}`. Аналогично неизвестное действие с null в известном праве.
Это нарушает требование Access «known typed values + lossless unknown jsontext.Value»
и общий контракт lossless Permissions. При read-modify-write роли меняется значение права.
Распознавать Actions только для объекта, в котором все значения — JSON strings;
остальные формы целиком сохранять в Raw. Добавить regression обоими codecs.

Остальных подтверждённых Standards defects и косметических smell-замечаний нет.

## Spec

1. **P2 — неизвестное значение permission null превращается в пустую строку.**
   `model/permission.go:67–71`. A02 требует «known typed values + lossless unknown
   jsontext.Value» и «отсутствие потерянных values». Объект
   `{"future":{"view":null,"update":"FUTURE"}}` после round-trip содержит
   `view:""`, Raw не заполнен. То же замечание независимо обнаружено Standards.
   Проверять строковую форму всех actions перед типизацией; иначе сохранять Raw.

2. **P2 — AttributeList сериализуется несовместимо с собственным decoder.**
   `metadata/metadata.go:50–52`. Общий контракт Access: JSON v1/v2; A05 требует
   сверить формы attributes/meta/rows/plain arrays.
   У AttributeList.Meta/Rows нет JSON tags или MarshalJSON, поэтому Marshal выдаёт
   `attributes:{"Meta":null,"Rows":[...]}`. UnmarshalJSON ожидает lowercase meta/rows
   и молча теряет строки. Entity с одним attribute после Marshal/Unmarshal содержит
   0 attributes, ошибок нет, оба codecs. Локальное сохранение metadata становится
   ненадёжным. Нужны корректная JSON-форма при Marshal и round-trip regression
   для array/collection форм, включая metadata вложенных custom entities.
