# moysklad-sdk-go

Go SDK для API МойСклад, общий для решений рабочей папки `moysklad/`.

Потребители фиксируют версию этого репо: изменение здесь — всегда отдельный тикет, который блокирует тикеты потребителей.

## Agent skills

Настройки скиллов, спеки, тикеты, глоссарий и ADR — в соседнем репо `../meta/` (клон `eteeet/meta` рядом с этим репо). See `../meta/AGENTS.md`.
