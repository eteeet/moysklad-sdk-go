# Domain docs

## Перед изучением кода

Пути ниже указаны относительно корня `moysklad-sdk-go`.

- Прочитай общий glossary `~/ETEEET/moysklad/meta/GLOSSARY.md` и `GLOSSARY.md` в корне, если он есть.
- Прочитай ADR из `docs/adr/`, относящиеся к текущей задаче.

Если документ отсутствует, продолжай без отдельного уведомления.
Не создавай пустые документы заранее.

## Glossary

Общий — `~/ETEEET/moysklad/meta/GLOSSARY.md`; термины только этого проекта — `GLOSSARY.md` в корне, создавай его с первым таким термином. Правило — `~/ETEEET/moysklad/AGENTS.md`, раздел Glossary.
Используй термины glossary в обсуждениях, задачах и коде; пробелы и противоречия разбирай через `domain-modeling`.

## Архитектурные решения

ADR этого SDK хранятся локально в `docs/adr/`.
Создавай их по мере появления существенных решений через `domain-modeling`.

Если предложение противоречит существующему ADR, явно укажи противоречие
и причину пересмотра, а не переопределяй решение молча.
