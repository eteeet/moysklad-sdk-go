# Issue tracker: Local Markdown

Задачи и спецификации этого репозитория хранятся в `.scratch/`.

## Соглашения

- Одна возможность — один каталог `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`.
- Нумерация начинается с `01`; один ticket — один файл.
- Статус записывается строкой `Status:` в начале файла.
- Значения статусов определены в `triage-labels.md`.
- Комментарии добавляются в конец файла под заголовком `## Comments`.

## Публикация

Когда skill требует опубликовать спецификацию или ticket,
создай соответствующий файл в `.scratch/<feature-slug>/`.

## Чтение задачи

Когда skill требует получить ticket, прочитай файл по указанному пути.
Если указан только номер, найди его в каталоге соответствующей возможности.

## Wayfinding

- Карта: `.scratch/<effort>/map.md`.
- Дочерние задачи: `.scratch/<effort>/issues/NN-<slug>.md`.
- Тип задачи: `Type: research`, `prototype`, `grilling` или `task`.
- Зависимости: строка `Blocked by: NN, NN`.
- Начинать можно после перехода всех зависимостей в `resolved`.
- Выбирай первую по номеру открытую, незаблокированную и незанятую задачу.
- Перед работой установи `Status: claimed`.
- После решения добавь раздел `## Answer`, установи `Status: resolved`
  и добавь краткий результат со ссылкой в Decisions-so-far файла карты.
