# Triage labels

| Роль skill | Статус tracker | Значение |
|---|---|---|
| needs-triage | needs-triage | Требуется оценить задачу |
| needs-info | needs-info | Ожидается дополнительная информация |
| ready-for-agent | ready-for-agent | Задача определена и готова для агента |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Задача не будет выполняться |

В локальном tracker статус хранится строкой `Status:` в файле задачи.
